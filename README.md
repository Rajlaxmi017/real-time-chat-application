## 📌 About The Project

The Real-Time Chat Application is a full-stack web application developed to enable instant communication between users through private and group chat features. The project is built using modern web technologies such as React.js, Node.js, Express.js, and Socket.io.

The main purpose of this application is to provide real-time messaging functionality where users can join chat rooms, send messages instantly, and communicate without refreshing the page. The application offers a clean and responsive user interface similar to modern chat platforms.

## 🚀 Project Functionality

The application allows users to enter a username and join a specific chat room. Once connected, users can send and receive messages instantly in real time. Messages are updated dynamically without reloading the webpage.

Socket.io manages the communication between frontend and backend by handling socket connections, broadcasting messages, and managing chat rooms efficiently. The system supports multiple users and rooms simultaneously, making the application scalable and interactive.

The responsive interface ensures smooth performance across desktops, tablets, and smartphones.
